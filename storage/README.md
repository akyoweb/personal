# storage
این پوشه فقط به‌عنوان پشتیبان (fallback) نگه داشته شده است.

مسیر پیش‌فرض لاگ پیام‌ها بیرون از وبروت است:

    C:\xampp\htdocs\personal-storage\messages.log
اگر آن مسیر روی سرور قابل نوشتن نبود، تابع `storage_dir()` در
`includes/functions.php` به همین پوشه برمی‌گردد و در نهایت به پوشه موقت سیستم.
فایل `.htaccess` هم برای همان حالت پشتیبان گذاشته شده تا دسترسی مستقیم
از طریق Apache بسته باشد.
